# 중앙 배경 선택: 기존 / 네온 HUD

## 선택기 위치 후속 수정

- 사용자 요청으로 네온 HUD 선택기를 우측 하단 빈 박스로 이동. 기존 스타일은 상단 유지. select는 하나만 유지하고 CSS로 재배치하며 네온 모드 상단 선택 행 제거.
- 관련 테스트 RED→GREEN 8개, 타입 검사·린트·전체 779개 테스트·빌드 통과. 데스크톱/모바일 배치와 양방향 전환 확인. 모바일 박스 가로 overflow 없음.

## 반영

- 사용자 참조 이미지의 배치 구조를 SVG/CSS로 재구성. 후속 지시에 따라 붉은색이 아닌 시안·블루 네온으로 최종 적용.
- 상단 왼쪽 모델 연결정보, 상단 오른쪽 카메라, 하단 왼쪽 START, 하단 오른쪽은 빈 슬롯.
- 중앙 상단 선택기로 기존 스타일 복귀 가능. 기본값 기존 스타일, 브라우저별 선택 저장 및 저장소 차단 시 세션 내 전환 유지.
- 카메라·음성 세션 소유권 변경 없음. 배경 전환 때 같은 카메라/리액터 노드 유지. 20초 이스터에그 보존.
- HUD 색상 변수는 scene에 한정하여 답변·입력 스타일에 상속되지 않음.

## 검증

- 선행 테스트: preference 모듈 부재에서 RED 확인 후 구현, 선택·복원·저장 오류·초기 레드 미리보기 값 호환 테스트 통과.
- 두 스타일의 선택 옵션, 카메라/리액터/START 단일성, 네 구역 명세, 빈 우측 하단을 정적 마크업으로 검사.
- `npm run typecheck` 통과, 관련 ESLint 통과, 전체 단위 테스트 92파일/779개 통과.
- 프로덕션 `npm run build` 통과. 최종 코드 검토 승인. 모바일 START는 약 44×44 CSS px, 검증 후 데스크톱 크기로 복귀하고 네온 HUD 선택 상태 유지.
- 기존 3010 화면에서 새로고침 후 선택 복원 확인. 실제 우주선 shoo 재생 중 기존→네온 전환 후 phase가 shoo로 유지됨을 확인(재시작 없음), 카메라 캔버스 1개.
- 데스크톱 및 390×844 모바일 네 구역 캡처/좌표 확인. 모델 박스 가로 overflow 없음. 카메라 실제 권한 요청·라이브 스트림 전환은 이번 검증 범위에 포함하지 않음.
- 다른 진행 중인 연출/음성/메뉴 변경 보존. 서버/포트 변경이나 커밋 없음.
