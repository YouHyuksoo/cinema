# 리액터 클릭 이스터에그

## 최종 확장: 메카닉 후면 + 20초 장난극

- 사용자 승인으로 두 요구를 함께 반영: 첫 고개 흔들기/퇴치 → 재방문/머리 위 착륙/장난 → 더 큰 흔들기/퇴치 → 세 번째 방문/도발 → 붉은 눈 안 불꽃 → 도주/급선회/격추 → 20초에 복귀.
- 후면: 깊이 있는 장갑 6개·냉각 홈 18개·굵은 구리관 3개·볼트 6개·베어링·돌출 육각축. 부품은 본체와 같은 회전/투영을 사용하고 실제 면을 깊이순으로 그린다.
- 검토에서 찾은 회전 경계 실루엣 누락 수정: 앞면 방향에서도 후면을 먼저 그린 뒤 본체가 가린다. 90도 경계 양쪽의 실제 Canvas 축 경로/그리기 순서 회귀 테스트로 RED→GREEN 확인.
- 착륙 다리/엔진 꺼짐, 본체 피치와 연결된 착륙 위치, 이륙 경계 좌표 연속성 검증. 내부 불꽃은 눈 윤곽 안에만 clip, 세 번째 방문 이전에는 발열 없음.
- 최종 검증: typecheck 통과, 변경 파일 ESLint 통과, 전체 89개 파일/762개 테스트 통과, 프로덕션 build 통과. 명세 및 코드 품질 검토 승인.
- 기존 3010 브라우저에서 데스크톱 및 390×844 모바일의 전체 20초 단계 모두 확인. 머리 위 착륙, 불타는 눈, 기계 후면과 레이저/폭발 캡처 확인. idle/재생 가능 상태 복귀, 브라우저 오류 로그 0건. 검증 후 화면 크기 원복.
- 기존 음성/마이크 실제 장치 연결, OS reduced motion, 숨김 및 Escape의 브라우저 경로는 이번 확장 검증에서 실행하지 않았다. 해당 순수 재생 컨트롤러 동작은 단위 테스트로 확인.
- 영향 경로 추가: reactorShipFlight.ts, reactorRearGeometry.ts, components/drawReactorRear.ts, components/drawReactorEyeHeat.ts. 공통 시각 규칙은 DESIGN.md 갱신. 다른 작업의 AI 변경 보존, 서버/포트 변경 및 커밋 없음.

## 초기 버전 기록 (아래 7.4초 구성은 위 최종 확장으로 대체)

- 리액터 클릭으로 약 7.4초 연출: 우주선 진입/장난 → 붉고 가늘어진 중앙 눈 → 뒤쪽 도주/가림 → 리액터 급선회 → 레이저/폭발 → 시안 눈과 기본 회전 복귀.
- 금속/코일 색, 옆면 문양, 끄덕임, 기존 음성 스파크는 보존. 별도 음성·카메라·네트워크 요청 없음.
- 중복 실행 무시, 취소 및 재실행, 동작 줄이기 정적 인사, 숨김/언마운트 정리를 연결.

## 검증

- `npm run typecheck`: 통과.
- 변경 파일 ESLint: 통과.
- `npm run test:unit`: 첫 실행은 sandbox `spawn EPERM`; 동일 명령 권한 재실행에서 별도 AI 설정 테스트 1개 실패(제공자 목록 차이). 후속 실행은 87개 파일, 752개 테스트 모두 통과. 해당 AI 테스트는 이 작업에서 수정하지 않음.
- `npm run build`: 권한 승인 경로에서 프로덕션 빌드 및 페이지 생성 통과.
- 기존 `http://localhost:3010/`에서 클릭 → 붉은 눈/장난, 뒤집힌 후면/레이저/폭발을 실제 캡처 확인. 모바일 390×844에서도 붉은 눈과 클릭 확인. 연출 종료 후 idle/calm 및 재생 가능 상태 확인.
- 브라우저 Escape 키 검증은 자동화 locator.press 제한으로 완료하지 못함. 순수 컨트롤러 취소는 단위 테스트 통과. 실제 마이크/AI 출력 장치 연결 및 OS 동작 줄이기/탭 숨김 경로는 이번 검증에 포함하지 않음.
- 다른 진행 중인 AI 설정/음성 변경은 보존. 포트/서버 변경, 커밋, 배포 없음.
