# HATCHERY 명령 매핑

텍스트 입력, 브라우저 음성, OpenAI Realtime 전사는 아래의 동일한 로컬 매핑을 먼저 실행한다. 화면 변경 성공 여부는 실제 화면 상태를 다시 읽어 확인한다. `그리고`로 이어 말한 명령도 순서대로 실행하며, Realtime 모델이 같은 도구 호출을 반복해도 화면 동작은 한 번만 실행한다.

## 장면 이동

공통 표현은 `보여줘`, `열어줘`, `이동해`, `전환해`, `틀어줘`, `재생해`다.

| 장면 ID | 화면 이름과 인식어 | 예시 |
|---|---|---|
| `wave` | 온습도, 온도, 습도 | `온습도 화면으로 전환해` |
| `gears` | 기어 | `기어 연동 보여줘` |
| `scan` | 설비 스캔, 스캔 | `설비 스캔 열어줘` |
| `unfold` | 지표, 지표 펼침 | `지표 화면 보여줘` |
| `trace` | 변화 추적, 추적 | `변화 추적 재생해` |
| `console` | 정보 콘솔, 정보창, 콘솔 | `정보창 열어줘` |
| `visor` | 바이저, 바이저 3D | `바이저 3D 보여줘` |
| `visorPan` | 바이저 평면 | `바이저 평면으로 이동해` |
| `bars` | 마운터 분석, 마운터 진단, 막대(호환 인식어) | `마운터 분석 보여줘` |
| `pie` | 차트 분석, 차트, 통합 차트·파이(호환 인식어) | `차트 분석 보여줘` |
| `corners` | 코너, 코너 전개 | `코너 전개 틀어줘` |
| `machine` | PCB, 기판, 자동차, 차량, 분해 | `PCB 검사 보여줘`, `자동차 보여줘` |
| `network` | 공정망, 공정 네트워크 | `공정망 보여줘` |
| `energy` | 에너지 | `에너지 파동 보여줘` |
| `product` | 제품 내부 검사, 내부 검사 | `제품 내부 검사 열어줘` |
| `spc` | SPC, 공정능력, 관리도 | `SPC 분석 보여줘` |
| `cctv` | CCTV, 씨씨티비, 감시 카메라 | `CCTV 감시로 전환해` |

`메인 메뉴로 가`, `홈 화면으로 이동해`, `메인으로 돌아가`는 메인 화면으로 복귀한다.

## 메뉴와 설정

| 대상 | 예시 | 값 또는 동작 |
|---|---|---|
| 작업메뉴·화면메뉴 | `작업메뉴 열어줘`, `화면 메뉴 펼쳐`, `구체형 네비게이션 메뉴 열어줘` | 좌측 하단 구체형 네비게이션, 구체링 열기 / 닫기 |
| 설정메뉴 | `설정메뉴 열어줘`, `설정 메뉴 접어` | 좌측 하단 터빈형 설정 메뉴 열기 / 닫기 |
| 터빈 메뉴 | `터빈 메뉴 펼쳐`, `터빈 메뉴 접어` | 좌측 하단 터빈형 설정 메뉴의 호환 별칭 |
| 관리 큐브 | `관리 큐브 메뉴 열어`, `큐브 메뉴 닫아` | 열기 / 닫기 |
| 연출 설정 | `연출 설정 열어줘`, `설정창 닫아` | 열기 / 닫기 |
| 현재 설정 | `설정 알려줘` | 변경 가능한 현재값 조회 |

## 화면·재생·차트

| 설정 | 예시 | 허용값 |
|---|---|---|
| 색상 테마 | `색상 테마 로즈로 변경해` | 시안, 에메랄드, 블루, 앰버, 로즈, 흰색 |
| 중앙 배경 | `중앙 배경 스틸 오비트로 변경해` | 네온 HUD, 시안 계기판, 스틸 오비트, 크림슨 코어, 시안 헥사, 블루 다이아몬드, 앰버 오비트 |
| 화면 질감 | `화면 질감 홀로그램으로 변경해` | 없음, 유리, 필름, 홀로그램, 물속, 우주 |
| 질감 강도 | `질감 강도 70퍼센트로 변경해` | 0–100 |
| 재생 속도 | `재생 속도 1.5로 변경해` | 0.25, 0.5, 0.75, 1, 1.5, 2, 3, 4배 |
| 재생 상태 | `재생해`, `재생 정지해` | 재생 / 정지 |
| 재시작 | `처음부터 다시 시작해` | 현재 연출 처음부터 |
| 재생 방식 | `재생 방식 현재 장면 반복으로 변경해` | 전체 연속 / 현재 장면 반복 |
| 재생 위치 | `재생 위치 12초로 이동해` | 현재 장면 길이 안의 초 |
| 검사 대상 | `검사 대상 자동차로 변경해` | PCB / 자동차 |
| 차트 분석 형식 | `차트를 산포로 변경해`, `차트 자동 순환으로 변경해` | 자동 순환 / 막대 / 선 / 영역 / 산포 / 파이 |
| 차트 분석 형태·두께 | `차트 형태 평면으로 변경해`, `차트 두께 80퍼센트로 변경해` | 평면 / 입체, 40–160% |
| 파이 형태·두께 | `파이 형태 입체로 변경해`, `파이 두께 120퍼센트로 변경해` | 평면 / 입체, 40–160% |

## 카메라와 장면 직접 조작

| 설정 | 예시 | 값 또는 동작 |
|---|---|---|
| 카메라 연결 | `카메라 연결 켜줘`, `카메라 연결 꺼줘` | 켜기 / 끄기 |
| 영상 창 | `영상 창 열어줘`, `영상 팝업 닫아` | 열기 / 닫기 |
| 거울·확대·블러 | `거울 모드 켜줘`, `카메라 줌 1.4로 변경해`, `얼굴 블러 30으로 변경해` | 거울 켜기/끄기, 줌 1–2, 블러 0–100 |
| CCTV 방식 | `CCTV 직접 감시로 변경해`, `CCTV 자동 순찰로 변경해` | 직접 감시 / 자동 순찰 |
| CCTV 선택 | `CCTV 3번 카메라 선택해` | 1–9번 |
| 3D 설비 방식 | `설비 직접 탐색으로 변경해`, `설비 자동 투어로 변경해` | 직접 탐색 / 자동 투어 |
| 3D 설비 선택 | `2라인 마운터 선택해` | 1–5라인의 로더·스크린프린터·SPI·마운터·MAOI·리플로우·AOI·언로더 |
| 3D 설비 시점 | `선택한 설비로 이동해`, `설비 입구 시점으로 이동해` | 선택 설비 초점 / 입구 시점 |
| 온습도 구역 | `ZONE 6 선택해`, `온습도 자동 순회로 변경해` | ZONE 01–10 / 자동 순회 |
| CCTV 순차 이동 | `다음 CCTV 카메라 보여줘`, `이전 CCTV 카메라` | 이전 / 다음 카메라 |
| 3D 설비 배율 | `3D 설비 화면 확대해`, `설비 화면 축소해` | 한 단계 확대 / 축소 |
| 3D 설비 선택 | `설비 선택 해제해` | 현재 선택 해제 |
| 온습도 순차 이동 | `다음 온습도 구역 보여줘`, `이전 구역 보여줘` | 이전 / 다음 구역 |
| 온습도 선택 | `온습도 구역 선택 해제해` | 자동 순회 상태로 복귀 |

## 메인 화면 객체

| 객체 | 예시 | 동작 |
|---|---|---|
| 상단 지표 | `상단 지표 스크롤 멈춰`, `상단 지표 스크롤 재개해` | 자동 스크롤 정지 / 재개 |
| 좌측 카드 | `왼쪽 카드 자동 스크롤 재개해` | 자동 스크롤 정지 / 재개 |
| 우측 카드 | `오른쪽 분석 카드 멈춰` | 자동 스크롤 정지 / 재개 |
| 좌우 카드 확대 | `생산 진행 카드 확대해`, `음성 설정 카드 보여줘` | 지정 카드를 중앙 확대 |
| 확대 카드 | `확대한 카드 닫아` | 중앙 확대 보기 닫기 |
| 신호 감지기 | `신호 감지기 실행해` | 상태 구체 공전 효과 실행 |
| 중앙 리액터 | `중앙 리액터 다음 효과 실행해` | 다음 이스터에그 효과 실행 |

드래그 회전, 팝업 이동·크기 조절처럼 연속 좌표가 필요한 조작은 화면 포인터·키보드로 수행한다. 단계형 확대·축소와 이름이 있는 카드 선택은 음성으로 처리한다.

## 음성·AI

| 설정 | 예시 | 허용값 |
|---|---|---|
| 목소리 | `목소리 여성으로 변경해` | 여성 / 남성 |
| 음성 방식 | `브라우저 음성으로 변경해`, `실시간 음성으로 변경해` | 브라우저 / OpenAI Realtime |
| AI 제공자 | `AI 제공자 Mistral로 변경해` | OpenAI API, ChatGPT, Anthropic, Gemini, Mistral |
| 채팅 모델 | `채팅 모델 gpt-5-mini로 변경해` | 해당 제공자의 모델 ID |
| 실시간 음성 모델 | `실시간 음성 모델 gpt-realtime-2.1-mini로 변경해` | OpenAI Realtime 모델 ID |
| 응답 다양성 | `temperature 0.4로 변경해` | 서버 허용 범위 |
| 최대 출력 토큰 | `최대 출력 토큰 1200으로 변경해` | 서버 허용 범위의 정수 |
| 추가 지시 | `추가 지시 "세 문장 이내로 답해"로 설정해` | 따옴표 안 문자열 |
| 시스템 프롬프트 | `시스템 프롬프트 "현장 데이터만 설명해"로 설정해` | 따옴표 안 문자열 |
| 현장 브리핑 | `현장 요약` | 현재 장면 데이터 요약 |

API 키·비밀번호 입력, 관리자 저장·삭제, 로그아웃, 파일 첨부는 음성 오인식으로 실행하면 안 되는 보안·관리 동작이라 직접 화면 조작만 허용한다. 이전 대화는 AI 문맥에만 짧게 유지하며 메인 좌측 카드에는 표시하지 않는다.

## 구현 접점

- 자연어 장면: `src/cinema/jarvisCommands.ts`
- 자연어 설정: `src/cinema/screenCommands.ts`
- 화면 실행과 상태 확인: `src/cinema/useScreenCommands.ts`
- 객체별 메서드 등록과 호출: `src/cinema/screenObjectRegistry.ts`, `src/cinema/ScreenObjectContext.tsx`

화면 객체는 `screen`, `player`, `camera`, `camera.popup`, `metrics`, `stream.left`, `stream.right`, `card.focus`, `scanner`, `reactor`, `menu.turbine`, `menu.cube`, `cctv`, `factory`, `environment` ID로 자신의 상태와 허용 메서드를 등록한다. 기존 `control_screen` 명령은 호환 계층에서 이 객체 메서드로 변환되므로 텍스트·음성·UI가 같은 실제 컨트롤러를 사용한다. 새 조작 객체를 추가할 때 DOM selector를 중앙 실행기에 추가하지 말고 객체가 메서드를 등록해야 한다.

키보드 `Escape`는 모든 재생 장면에서 `screen.stopAndHome`을 실행한다. 음성·카메라·재생과 장면별 수동 조작을 중지하고 열린 오버레이를 닫은 뒤 메인 화면으로 복귀한다. 반복 keydown은 무시하며 장면 내부 효과 취소 핸들러에도 이벤트를 계속 전달한다.
- 브라우저 음성: `src/cinema/useJarvisLocalVoice.ts`
- Realtime 전사: `src/cinema/jarvisRealtimeSession.ts`
- 음성·AI 서버 저장: `src/cinema/useJarvisVoice.ts`
- 장면 객체 데이터: `src/cinema/hatcheryTargets.ts`, `docs/standards/scene-data-contract.md`
