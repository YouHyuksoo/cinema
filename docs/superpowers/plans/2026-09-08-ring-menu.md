# 3D Ring Menu Implementation Plan

> **For agentic workers:** Use executing-plans to implement this plan task-by-task.

**Goal:** 승인한 기울어진 3D 링에서 기존 16개 메뉴를 회전·정렬하고 명시적으로 실행한다.

**Architecture:** filmMenuRing.ts의 순수 순환 인덱스·원근 배치 계산, useFilmMenuRing.ts의 포인터/선택 상태, FilmChapterMenu.tsx의 접근 가능한 메뉴, filmMenuRing.module.css의 공간 표현으로 분리한다. 기존 FilmDock 선택 콜백·아이콘·모바일 접힘과 장치 수명은 유지한다.

**Tech Stack:** React, CSS 3D transforms, Pointer Events, Vitest. 새 의존성 없음.

## Approved design and boundaries

- 바닥에 기울어진 링. 앞쪽은 크고 선명하고 뒤쪽은 작고 흐리다. 현재 색상 테마와 육각 아이콘 재사용.
- 좌우 드래그/스와이프·이전/다음 버튼·방향키로 회전. 놓으면 정면 인덱스로 스냅.
- 비정면 메뉴 클릭은 정렬만, 정면 클릭/Enter는 실행. 드래그 후 click은 실행 방지. 이동 취소는 스냅만 수행.
- 모든 메뉴는 키보드 접근 가능, focus 시 정면 정렬. 실제 재생 중 메뉴와 탐색 중 메뉴를 별도로 표시.
- 모바일 기본 접힘 유지. 링은 열린 패널 안에 맞춘다. 데스크톱 하단 여백만 높인다. 줄어든 동작 설정은 전환 생략.
- 중앙 확대/중앙 고정은 이번 작업에 포함하지 않는다. 자동 장치 시작이나 네트워크 요청 추가 없음. 커밋 요청 없음.
