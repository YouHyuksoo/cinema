# 온습도 ZONE 객체 선택 1단계 설계

## 목표

온습도 모니터링(`wave`) 장면의 ZONE 카드를 단순히 그려지는 도형이 아니라 식별하고 선택할 수 있는 장면 객체로 다룬다. 사용자가 카드 하나를 클릭하면 해당 카드와 중앙 온도·습도 계기의 연결 및 강조가 유지되고, 빈 공간을 클릭하면 선택이 해제된다.

이번 단계는 객체 제어 가능성을 작은 범위에서 검증하는 작업이다. 센서 값 편집, 위치 이동, 표시 여부 변경, 경고 상태 변경은 포함하지 않는다.

## 현재 구조

- `SignalFilm.tsx`의 단일 Canvas가 모든 연출을 표시한다.
- `useFilmPlayback.ts`가 공통 시간축으로 프레임을 다시 그린다.
- `drawWaveFilm.ts`는 `zoneEnvironmentState()`에서 계산된 카드·계기·히트맵 상태를 그린다.
- 자동 순회가 현재 선택 ZONE을 결정한다.
- SMT 공장 장면은 Canvas 위 입력 계층과 좌표 판정을 통해 개별 설비 선택을 이미 지원한다.

## 선택한 접근법

Canvas 좌표 판정 방식을 사용한다. 기존 Canvas 렌더링과 시간축은 유지하고, 온습도 카드의 계산된 화면 형상에서 선택 가능한 장면 객체를 만든다.

투명 DOM 버튼을 카드 위에 겹치는 방식은 카드의 부유·기울기·배율과 별도 DOM 좌표를 지속해서 동기화해야 하므로 사용하지 않는다. 장면 전체를 SVG 또는 DOM 객체로 전환하는 방식도 이번 검증 범위를 넘어선다.

## 객체 모델과 책임

### ZONE 장면 객체

각 선택 가능 객체는 최소한 다음 의미를 제공한다.

- 안정적인 식별자: 기존 ZONE 코드
- 객체 종류: 온습도 ZONE 카드
- 현재 화면 형상: 카드의 부유 위치, 배율, 기울기가 반영된 클릭 판정 영역
- 연결된 도메인 데이터: 온도, 습도, 관리 범위와 상태

객체 모델은 그리기 함수를 직접 소유하지 않는다. 기존 상태 계산과 레이아웃을 이용해 렌더링과 입력 판정이 같은 좌표 기준을 공유하게 한다.

### 상호작용 상태

온습도 전용 상호작용 컨트롤러가 수동 선택 ZONE ID를 보관한다. 고빈도 포인터 이동 상태는 만들지 않으며 클릭 결과만 React 상태로 공개한다.

- 카드 클릭: 해당 ZONE 선택
- 빈 공간 클릭: 선택 해제
- 다른 장면으로 이동: 선택 상태 제거
- 자동 재생·일시정지·탐색: 기존 동작 유지

### 입력 계층

`wave` 장면일 때만 Canvas 위에 입력 계층을 활성화한다. 실제 Canvas 크기, CSS 표시 크기, DPR, film viewport 변환을 역산하여 논리 좌표를 얻는다. 이 좌표로 현재 화면에 보이는 카드들을 검사하며, 보이지 않는 카드는 선택하지 않는다.

## 렌더링 우선순위

수동 선택이 없으면 기존 시간 기반 자동 ZONE 순회를 그대로 사용한다. 수동 선택이 있으면 해당 ZONE이 카드 강조와 중앙 계기 값·연결선의 기준이 된다. 기존 카드 등장·퇴장, 계기 조립, 그래프 및 히트맵 전환 타이밍은 유지한다.

수동 선택을 시각적으로 구분하되 현재 디자인 언어를 따른다. 선택 카드의 외곽선·접점·연결선과 중앙 계기를 강조하며 별도의 사각 HTML 선택 테두리를 추가하지 않는다.

## 경계 조건

- 카드가 퇴장했거나 히트맵 단계로 전환된 뒤에는 클릭 판정을 제공하지 않는다.
- 잘못된 ZONE ID는 무시하거나 선택 해제로 정규화한다.
- Canvas 밖, NaN 또는 무한대 좌표는 선택하지 않는다.
- 카드의 부유, 기울기와 배율이 바뀌어도 보이는 형상과 클릭 영역이 어긋나지 않아야 한다.
- `prefers-reduced-motion`, 배속, 탐색 위치에서도 동일한 장면 시간으로 판정을 재현한다.

## 테스트 전략

TDD로 다음 순서대로 검증한다.

1. 현재 시간의 카드 중심을 클릭하면 해당 ZONE 객체가 선택된다.
2. 카드 밖을 클릭하면 선택 대상이 없다.
3. 숨겨진 카드와 유효하지 않은 좌표는 선택되지 않는다.
4. 부유·배율·기울기가 적용된 카드 경계의 안/밖 판정이 렌더링 좌표와 일치한다.
5. 수동 선택이 자동 선택보다 우선하고, 해제 후 자동 순회로 복귀한다.
6. 입력 계층에서 선택·해제되고 장면 전환 시 상태가 정리된다.
7. 기존 온습도 장면 단위 테스트와 전체 typecheck, unit test, build를 실행한다.

## 변경 영향 경로

예상 영향 경로는 다음과 같다.

`zoneEnvironment.ts` / `environmentLayout.ts` → 온습도 객체·좌표 판정 모듈 → 온습도 상호작용 훅·입력 계층 → `SignalFilm.tsx` / `useFilmPlayback.ts` → `drawWaveFilm.ts`

공통 시각 규칙과 최종 영향 경로는 구현 완료 시 `DESIGN.md`에 반영한다.

## 완료 기준

- 온습도 ZONE 카드가 안정적인 ID와 계산된 클릭 영역을 가진다.
- 사용자가 화면에서 카드 하나를 클릭해 선택하고 빈 공간 클릭으로 해제할 수 있다.
- 선택된 ZONE이 카드·연결선·중앙 계기에 일관되게 반영된다.
- 기존 자동 연출과 다른 15개 장면의 동작은 회귀하지 않는다.
- 프로젝트 표준 검증 명령이 통과한다.
