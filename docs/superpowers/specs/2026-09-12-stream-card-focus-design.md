# 좌우 스트림 카드 중앙 확대 설계

## 목적

HATCHERY 메인 화면의 좌우 자동 스크롤 영역에 있는 모든 직접 하위 카드를 선택하면 카드가 화면 중앙으로 이동해 확대 표시되어야 한다. 작은 카드의 수치, 그래프, 도움말을 읽기 쉽게 만드는 기능이며 기존 카드 내부의 설정, 선택, 분석 이동 기능은 그대로 유지한다.

## 범위

- `JarvisStream`의 `.content > section`으로 렌더링되는 좌측·우측 카드 전체를 확대 대상으로 삼는다.
- 연출 설정, 연결 상태, AI 모델, 음성 설정, 대화 이력, 도움말, 현장 게이지, 생산, 공정, 병목, 품질, 에너지, 검사, 온도 알림 카드를 포함한다.
- 카드 안의 `button`, `a`, `input`, `select`, `textarea`, `summary`, `label`과 명시적인 대화형 역할을 선택하면 카드 확대를 시작하지 않고 기존 기능만 실행한다.
- 상단 가로 지표, 중앙 음성 화면, 하단 브리핑은 대상에서 제외한다.

## 선택한 방식

공통 카드 확대 레이어를 사용한다. 원본 카드는 좌우 스트림 안에 그대로 두고, 선택 시 현재 DOM 표현을 중앙 레이어에 시각 복제한다. 복제본의 읽기 내용은 접근성 트리에 유지하고 대화형 요소만 비활성화해 중복 입력과 중복 API 호출을 방지한다. 설정과 명령은 원본 카드에서만 실행된다.

실제 React 노드를 스트림 밖으로 이동하면 React 소유권과 상태가 깨질 수 있다. 카드별 전용 확대 컴포넌트는 모든 카드마다 중복 구현이 필요하다. 공통 읽기 전용 복제 방식이 현재 구조에서 가장 작은 변경으로 모든 카드에 동일한 동작을 제공한다.

Canvas가 카드에 추가되는 경우 단순 `cloneNode`로 픽셀이 복제되지 않으므로, 복제 단계에서 원본과 복제본의 canvas를 순서대로 대응해 `drawImage`로 현재 프레임을 복사한다. SVG와 일반 DOM은 그대로 복제한다.

복제본의 모든 `id`에는 열기 횟수별 고유 접두사를 붙인다. `for`, `aria-labelledby`, `aria-describedby`, `aria-controls`, `href`, `xlink:href`, SVG `url(#...)` 속성과 인라인 스타일의 ID 참조도 같은 매핑으로 다시 쓴다. 원본 DOM과 확대 DOM 사이에 중복 ID가 남지 않아야 한다.

## 구성 요소

### `JarvisStream`

- 직접 하위 `section`에 확대 가능 카드 표식과 키보드 초점을 제공한다.
- 이벤트 위임으로 카드 배경 클릭을 감지한다.
- 대화형 하위 요소에서 시작한 클릭은 무시한다.
- 카드 자체에 초점이 있을 때 `Enter` 또는 `Space`로 확대를 요청한다.
- 선택 카드의 DOM 요소, 스트림 제목, 좌우 위치를 상위 콜백에 전달한다.
- 확대가 열려 있는 동안 `useDriftScroll`에 별도의 `suspended` 입력을 전달해 양쪽 자동 스크롤을 멈춘다. 사용자가 누른 `paused` 상태는 변경하지 않으며, 표시용 정지 상태는 `paused || suspended`로 계산한다.

### `JarvisCardFocus`

- `document.body` portal로 렌더링하는 단일 공통 레이어다.
- `role="dialog"`, `aria-modal="true"`, 카드에서 얻은 제목을 제공한다.
- 원본 카드의 시각 복제본을 담는다. 복제된 `button`, 링크, 입력 요소, `summary`, `label`과 대화형 역할에는 `disabled` 또는 `aria-disabled`, `tabIndex=-1`, `pointer-events:none`을 적용하고 링크 목적지를 제거한다. 복제 컨테이너의 캡처 단계에서 `click`, `pointerdown`, `keydown`, `input`, `change`, `toggle`, `submit` 이벤트의 기본 동작과 전파도 차단해 `<summary>` 토글과 label 위임을 포함한 네이티브 활성화를 막는다. 일반 제목, 설명, 수치, 그래프의 접근성 이름은 유지한다.
- portal 루트 안에 `jarvisStream.module.css`의 `content` 구조와 카드 클래스를 재현한다. 원본 카드의 계산된 `--film-accent`, `--film-accent-soft`, `--film-panel`, `--film-line`, `--film-ink`, `--film-muted`, `--film-bg`, 글꼴 변수를 허용 목록으로 복사해 현재 테마와 동일하게 표시한다.
- 원본 카드의 화면 좌표에서 중앙 목표 좌표로 이동·확대하는 FLIP 전환을 수행한다.
- 배경 클릭, 닫기 버튼, `Escape`로 닫는다.
- 열릴 때 닫기 버튼으로 초점을 이동하고 닫힐 때 원본 카드로 초점을 복원한다.
- 선택한 원본 카드가 언마운트되거나 장면이 바뀌면 즉시 닫는다.

### `JarvisMain`

- 현재 확대 카드 상태를 한 곳에서 소유한다.
- 좌우 `JarvisStream`에 같은 확대 콜백과 열림 상태를 전달한다.
- `JarvisCardFocus`를 한 번만 렌더링한다.

## 화면과 전환

- 확대 레이어는 전체 화면을 어둡게 덮되 중앙 HUD와 색상 테마는 보이도록 반투명 검정 배경을 사용한다.
- 목표 크기는 `min(760px, calc(100vw - 32px))`, 최대 높이는 `calc(100dvh - 40px)`로 제한한다.
- 복제 카드는 중앙에서 자체 스크롤을 허용한다. 원본 스트림의 3D 기울기, 깊이 이동, 마스크는 제거한다.
- 카드 테두리, 절단 모서리, 테마 액센트는 원본 스타일을 유지한다.
- 열기와 닫기는 원본 좌표와 중앙 좌표 사이를 280ms 동안 이동한다.
- `prefers-reduced-motion`에서는 이동 없이 중앙 확대 상태를 즉시 표시한다.
- 열림 상태에서 다른 카드 배경을 선택할 수 없으며 먼저 닫아야 한다.

## 상호작용 규칙

1. 카드 배경 클릭 또는 카드 초점 상태에서 `Enter`/`Space`를 누르면 확대한다.
2. 내부 대화형 요소를 누르면 카드 확대 없이 원래 기능을 실행한다.
3. 확대 복제본은 읽기 전용이다.
4. 확대 중 좌우 스트림 자동 이동과 카드 스캔 애니메이션을 멈춘다.
5. 닫으면 두 스트림은 기존 일시정지 상태를 보존한 채 자동 이동 조건을 다시 계산한다.
6. 빠른 연속 클릭은 첫 열기 또는 닫기 전환이 끝날 때까지 무시한다.

## 접근성

- 카드에는 `tabIndex=0`과 카드 제목 기반 `aria-label`을 부여한다. 이미 의미 있는 영역 레이블이 있으면 재사용한다.
- 카드 내부에서 `Enter`나 `Space`를 누른 경우에는 확대 키보드 처리로 전파하지 않는다.
- 확대 레이어는 modal dialog로 읽히며 닫기 버튼을 첫 초점으로 둔다.
- dialog가 열리면 portal 컨테이너를 제외한 `document.body`의 직계 자식 HTMLElement 각각의 기존 `inert` 값을 기록한 뒤 `true`로 설정한다. 닫거나 언마운트할 때 기록한 값으로 복원한다.
- 확대 복제본에는 초점 가능한 요소가 없고 닫기 버튼만 초점 대상이다. `Tab`과 `Shift+Tab`은 닫기 버튼에 머물도록 처리해 modal 내부에 초점을 가둔다.
- 닫기 후 원본 카드가 남아 있으면 해당 카드로 초점을 복원한다.

## 오류와 경계 처리

- 제목을 찾지 못하면 스트림 제목과 카드 순번으로 레이블을 만든다.
- 원본 크기가 0이거나 DOM에서 분리된 경우 이동 애니메이션 없이 중앙에서 연다.
- 복제 중 canvas 복사나 ID 참조 재작성에 실패한 개별 요소가 있어도 나머지 DOM과 SVG는 표시하되, 중복 ID가 남는 노드는 ID를 제거한다.
- 창 크기가 바뀌면 중앙 목표 크기만 다시 계산하고 dialog를 화면 안에 유지한다.
- 확대 중 장면 전환 또는 메인 화면 언마운트 시 portal과 복제 DOM을 정리한다.

## 검증

- 단위 테스트: 모든 직접 하위 카드가 확대 표식을 받는지, 내부 대화형 요소가 제외되는지, 키보드 열기와 닫기, 제목 추출, 외부 정지 전달을 확인한다.
- 단위 테스트: 확대 복제본의 읽기 내용은 남고 대화형 요소만 비활성화되는지, 캡처 단계의 활성화 차단이 `summary`, label, 링크, 역할 기반 컨트롤에 적용되는지, ID와 SVG 참조가 고유 접두사로 함께 변경되는지, dialog 역할과 닫기 버튼을 제공하는지 확인한다.
- 브라우저 검증: 좌우 대표 카드와 설정 카드에서 배경 클릭 확대, 내부 버튼 원래 동작, 닫기 후 초점 복원, 자동 스크롤 정지를 확인한다.
- 브라우저 검증: 현재 테마가 확대본에 유지되는지, 중복 DOM ID가 없는지, 스크린리더가 확대 내용을 읽을 수 있는지, 반복 열기·닫기 후 초점과 기존 `inert` 상태가 복원되는지 확인한다.
- 브라우저 검증: 데스크톱, 좁은 세로 화면, reduced motion에서 카드가 화면 밖으로 나가지 않는지 확인한다.
- 프로젝트 검증: `npm run typecheck`, 관련 단위 테스트, `npm run build`를 실행한다.

## 영향 경로

`JarvisMain` → `JarvisStream` / `useDriftScroll` → 새 `JarvisCardFocus`와 스타일 → 좌우 스트림의 모든 직접 하위 카드.
